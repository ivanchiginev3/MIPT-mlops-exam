# ADR-001: Выбор архитектуры на основе Metrics Driven Development

## Статус

Принято

## Дата

31.05.2026

## Контекст

В рамках проектирования ML-системы для предсказания оттока клиентов необходимо выбрать архитектурное решение для production-сервиса.

Для принятия решения были предоставлены результаты измерений времени отклика двух реализаций системы:

* Архитектура A — существующая система.
* Архитектура B — улучшенная система.

Были собраны выборки времени ответа (latency) для каждой реализации.

Среднее время ответа:

* Архитектура A: около 3.5 секунд.
* Архитектура B: около 2.0 секунд.

## Проблема

Необходимо определить, является ли наблюдаемое снижение времени ответа статистически значимым и следует ли переводить пользователей на новую архитектуру.

## Гипотезы

### H0

Среднее время отклика существующей и улучшенной систем одинаково.

### H1

Среднее время отклика улучшенной системы меньше, чем у существующей.

## Метод анализа

Для сравнения двух независимых выборок использовался двухвыборочный t-тест Уэлча (Welch's t-test).

Уровень значимости:

α = 0.05

Причины выбора теста:

* выборки независимы;
* размеры выборок велики;
* дисперсии могут различаться.

## Исходные данные

Для анализа использовались два набора данных времени отклика системы:

* Existing System Responses — существующая архитектура;
* Improved System Responses — улучшенная архитектура.

Данные были сгенерированы в рамках задания и использовались для демонстрации подхода Metrics Driven Development.

Средние значения:

* Existing System ≈ 3.5 сек;
* Improved System ≈ 2.0 сек.

## Результаты статистического теста

Результаты Welch's t-test:

T-statistic = 1875.079

P-value ≈ 0.0

Полученное значение p-value значительно меньше уровня значимости α = 0.05.

Следовательно, нулевая гипотеза H0 отвергается.

Различия между двумя архитектурными решениями являются статистически значимыми.

## Decision

На основании результатов статистического анализа принято решение считать улучшенную архитектуру предпочтительной.

Основания:

* H0 отвергнута;
* p-value < 0.05;
* улучшенная система демонстрирует статистически значимое снижение времени отклика.

В рамках учебного сценария рекомендуется использовать архитектуру B в качестве основной производственной архитектуры.
