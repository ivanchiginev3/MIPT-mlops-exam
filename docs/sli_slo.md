# SLI/SLO ML-системы

## 1. Назначение документа

Документ описывает индикаторы надежности и качества ML-системы для предсказания оттока клиентов банка.

SLI показывает, что именно измеряется.

SLO задает целевое значение, при котором система считается работающей нормально.

## 2. Технический уровень

| Компонент | SLI | SLO |
|---|---|---|
| API | Доля успешных запросов | Не менее 99% |
| API | Среднее время ответа | Не более 500 мс |
| API | Доля ошибок 5xx | Не более 1% |
| Docker container | Статус контейнера | `Up (healthy)` |
| CPU | Средняя загрузка процессора | Не более 80% |
| RAM | Использование оперативной памяти | Не более 85% |

## 3. Модельный уровень

| Компонент | SLI | SLO |
|---|---|---|
| Model quality | ROC-AUC | Не ниже 0.85 |
| Model quality | Precision | Не ниже 0.60 |
| Model quality | Recall | Не ниже 0.60 |
| Model quality | F1-score | Не ниже 0.60 |
| Data quality | Data drift | PSI не выше 0.2 |
| Predictions | Prediction drift | Изменение распределения предсказаний не более 10% |

## 4. Текущие метрики модели

## 5. Бизнес-уровень

| Компонент | SLI | SLO |
|---|---|---|
| Churn | Доля ушедших клиентов | Снижение на 5–10% |
| Retention | Доля удержанных клиентов | Рост не менее чем на 5% |
| Marketing | Доля клиентов высокого риска, попавших в кампанию удержания | Не менее 80% |
| Business value | Эффективность кампании удержания | Рост успешных удержаний не менее чем на 10% |

## 6. Реакция на нарушение SLO

Если нарушены технические SLO:

- проверить логи API;
- проверить статус Docker-контейнера;
- проверить нагрузку CPU/RAM;
- при необходимости перезапустить сервис.

Если нарушены модельные SLO:

- проверить качество входных данных;
- проверить data drift и prediction drift;
- запустить переобучение модели;
- сравнить новую модель с текущей через MLflow;
- заменить модель только при улучшении ключевых метрик.

Если нарушены бизнес-SLO:

- проверить корректность порога классификации;
- пересмотреть стратегию удержания клиентов;
- провести дополнительный анализ ошибок модели;
- обновить признаки или обучающую выборку.

## 7. Использование в MLOps-пайплайне

SLI/SLO используются для принятия решений о состоянии ML-системы.

Если новая модель не достигает минимальных SLO, она не переводится в production.

Если текущая модель перестает соответствовать SLO, запускается процесс переобучения и сравнения моделей.
